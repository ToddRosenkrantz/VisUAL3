# Credits

## VisUAL3

VisUAL3 (2026) was developed by Todd Rosenkrantz from VisUAL2: GNU assembler syntax, new instructions, the C Call panel, and a port to current tools.

## VisUAL2

VisUAL3 is built on [VisUAL2](https://github.com/ImperialCollegeLondon/Visual2), created by **Dr T. Clarke** and the 2018 third-year HLP students in the Department of Electrical and Electronic Engineering, **Imperial College London**, who wrote and tested it. Dr Clarke gave permission for VisUAL2 to be released under the GNU General Public License version 3.

Substantive contributors named in the [VisUAL2 acknowledgements](https://github.com/ImperialCollegeLondon/Visual2/wiki/Acknowledgements):

- Angelos Filos (created the initial Monaco–Fable skeleton)
- Lorenzo Silvestri
- Thomas Carotti
- Douglas Brion
- Christopher Macca

Code was also contributed by David Rovick Arrojo and the GitHub user Ben20082010, and the original About box thanked HLP Team 10. Many more of the 2018 HLP students tested VisUAL2.

The demonstration program `app/samples/karatsuba.s` was written by ls2617 (EIE1, Karatsuba code) and TJWC (testbench).

## VisUAL

VisUAL2 was inspired by **Salman Arif**'s [VisUAL](https://salmanarif.bitbucket.io/visual/), created as his MEng final-year project at Imperial College London.

## Starter template

VisUAL2 began from [arm-monaco](https://github.com/filangelos/arm-monaco) by Angelos Filos, licensed under the Apache License 2.0.
